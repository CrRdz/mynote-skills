# 可选风格参考

以下案例提炼自用户的课堂笔记，仅用于说明表达方式。无需读取原始文件即可使用；不要把案例主题、课程编号或章节结构当作新任务的要求。

完整的输入与输出见[课件与笔记对照导读](paired-example/guide.md)，包含源 PDF、用户笔记快照及其引用的全部图片。

## 来源与抽象原则

- **L1：简练定义与具体读图。** 英文要点旁补中文释义；图后说明颜色、坐标方向和趋势。对应原则：概念简写，视觉信息具体解释。
- **L2：难点分步展开。** 在矩阵、求导等难点处解释符号含义，并用小例子衔接一般公式。对应原则：仅在理解容易中断的位置补中间步骤。
- **用户修改后的 L3：术语就近解释与准确定位。** 中文紧贴英文概念，说明明确到具体面板和区域。对应原则：解释与对象就近对应，避免泛泛指图。

以下数学例子是写法示范；其他学科应替换为适合该主题的概念、论据和解释。

## 示例：定义后紧跟解释

```markdown
- Data is **linearly separable 线性可分** if a linear decision rule can classify every training example correctly.
  即存在一个线性决策边界，能够正确区分所有训练样本。
```

复用中英衔接方式，不必照抄用户速记中的语法或拼写错误。

## 示例：解释关键推导步骤

```markdown
**1. 先看一个样本**

$$
y^{(i)}=\sum_{k=1}^{D}w_kx_k^{(i)}+b
$$

对 $w_j$ 求偏导时，输入数据和其他权重都视为常数，所以只有含 $w_j$ 的一项留下来：

$$
\frac{\partial y^{(i)}}{\partial w_j}=x_j^{(i)}
$$
```

只在可能卡住理解的位置展开，不要求每个公式都从最基础定义证明。

## 示例：说明裁图中的对象

> **右图 Weight Space：** 阴影区域表示同时满足约束的权重组合。图中的点是一组权重，不是训练样本。
